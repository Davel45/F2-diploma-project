## Зведена матриця нефункціональних інженерних вимог (NFRs Matrix)

| ID вимоги (ISO 29148) | Категорія | Ключовий показник / Метрика | Цільове значення (стандарт 2026 р.) | Метод інженерного аудиту |
| :--- | :--- | :--- | :--- | :--- |
| **[`SRS-NFR-PERF-01`](srs.md#srs-nfr-perf-01)** | **Продуктивність** | Навантаження (RPS) | **500 RPS** (стабільне), пікове — **до 1000 RPS** | Стрес-тести Gatling / Grafana k6 |
| **[`SRS-NFR-PERF-02`](srs.md#srs-nfr-perf-02)** | **Продуктивність** | Latency p95 (читання слотів) | **<= 150 мс** (`p95`), **<= 300 мс** (`p99`) | Prometheus + Micrometer |
| **[`SRS-NFR-PERF-03`](srs.md#srs-nfr-perf-03)** | **Продуктивність** | Latency p95 (бронювання слота) | **<= 250 мс** (`p95`), **<= 500 мс** (`p99`) | Навантажувальне тестування |
| **[`SRS-NFR-SEC-01`](srs.md#srs-nfr-sec-01)** | **Безпека** | Автентифікація та сесії | **TLS 1.3**, **Stateless JWT** (access: 15 хв, refresh: 7 діб) | Spring Security Test |
| **[`SRS-NFR-SEC-02`](srs.md#srs-nfr-sec-02)** | **Безпека** | Шифрування медкарт (EMR) | **AES-256-GCM** на рівні полів таблиць | Криптографічний аудит / JUnit 5 |
| **[`SRS-NFR-SEC-03`](srs.md#srs-nfr-sec-03)** | **Безпека** | Цілісність рецептів та аудит | Контрольний хеш **SHA-256** у PDF; **Audit Log** (365 діб) | Автоматична валідація хешів |
| **[`SRS-NFR-SEC-04`](srs.md#srs-nfr-sec-04)** | **Безпека** | Захист від перевантаження (Rate Limit) | **Token Bucket (Redis):** <= 60 req/min на IP (`HTTP 429`) | Postman / Newman Suite |
| **[`SRS-NFR-REL-01`](srs.md#srs-nfr-rel-01)** | **Надійність** | Захист від овербукінгу | **0 колізій** подвійного запису при 100 одночасних потоках | Testcontainers Concurrency Test |
| **[`SRS-NFR-REL-02`](srs.md#srs-nfr-rel-02)** | **Надійність** | Доступність та відновлення | **>= 99.9%** (три дев'ятки), **RPO <= 1 хв**, **RTO <= 5 хв** | Spring Boot Actuator Health |
| **[`SRS-NFR-REL-03`](srs.md#srs-nfr-rel-03)** | **Відмовостійкість** | Ізоляція зовнішніх інтеграцій | **RabbitMQ Retry** (3 спроби, backoff) + **DLQ** | Testcontainers Toxiproxy |
| **[`SRS-NFR-MAINT-01`](srs.md#srs-nfr-maint-01)** | **Супроводжуваність** | Якість коду та тести | **SonarQube Quality Gate** (Coverage **>= 80%**, Debt <= 5%) | SonarQube + ArchUnit |
| **[`SRS-NFR-MAINT-02`](srs.md#srs-nfr-maint-02)** | **Інфраструктура** | Контейнеризація та безпека образів | **Docker Compose** (старт <= 90 с), **0 CRITICAL CVE** | GitHub Actions CI/CD + Trivy |
